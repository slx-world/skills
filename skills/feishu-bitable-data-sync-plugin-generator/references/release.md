# 联调与发布

按用户选择的环境部署，前端和后端均需平台可达的 HTTPS 地址。不要为了开发插件默认购买托管、开启公网隧道或更改企业可见范围。指南介绍 Replit 和申请飞书托管，不代表这些方案是必选或当前免费。

## 自定义同步应用调试

1. 本地通过协议测试和前端构建，配置实际 CONFIG_UI_URL 和与飞书一致的 Verification token。
2. 检查服务根地址的 `/meta.json`、其中的配置页和两个 POST URI。服务地址填入平台时不带末尾斜杠。
3. 打开有管理权限的多维表格，从页面左下角进入“从其他数据源同步”，选择“自定义同步应用”，填写服务地址与 Verification token。
4. 运行并完成配置页，下一步应进入平台字段配置；保存并同步时检查表结构、完整分页、错误显示、配置修改后恢复行为。

普通浏览器只验证页面；飞书 SDK bridge、真实数据源和最终同步结果必须分别验证。GET 浏览器地址栏不能代替带签名的回调 POST。

## 共享/上架

指南写有“申请共享自定义同步应用”及发布表单。但在2026-10-20，正文内嵌的旧表单显示“已停用，请勿提交”，其替代链接文案针对工作流插件，不能直接认作同步插件的有效入口。

需要上架时先核对当前飞书多维表格开发者的发布渠道、托管要求、企业内/公开可见性、审核资料和协议；无法核实则把发布列为待确认，仍交付完整工程与部署信息。不要自动提交停用表单、申请不相关插件类型或代表用户接受协议。

指南描述 syncType/syncStrategy 的上下文不等于已经配置实时同步。平台定时策略由 Base 设置，事件触发的可用性、注册方法和授权要另行核实。这个模板是平台拉取的只读数据源，不实现外部系统写回。

# 钉钉 AI 表格数据源插件起点

本工程使用固定示例订单，尚未连接真实数据库/API。服务端 Node.js >=20.6，无运行时外部依赖；前端需要构建。协议整理日期 2026-10-20。

1. `npm test`：执行签名及两个回调的本地协议测试。
2. 复制 `.env.example` 为 `.env`，设置 `DINGDOCS_SECRET` 为与钉钉配置相同的真实密钥。
3. 在 `frontend/` 执行 `npm install`、`npm run build`，保存生成的 lockfile。
4. 在工程根目录执行 `npm start`，访问 `http://127.0.0.1:8787` 检查页面。普通浏览器没有钉钉宿主，下一步按钮需在宿主初始化后才能启用。
5. 修改 `server/adapter.mjs` 接入用户授权的数据源；前端只保存连接选择，不保存密码。完善服务端连接身份映射、字段映射、稳定分页、查询超时和业务测试。
6. 使用用户选择的 HTTPS 部署环境，注册前端 URL 和 POST `/api/sheet_meta`、POST `/api/records`。默认 HOST 仅监听本地，实际部署按入口代理拓扑配置，不自动开启隧道。

前端 SDK 0.3.2 来自指南推荐 demo 的依赖版本，构建工具固定为已验证的 esbuild 0.25.12。SDK 根入口也导出 Node CLI，当前模板直接引用已核对的 dist-web/initView.js 以避免将 CLI 打入浏览器包；升级 SDK 时重新核对这个路径。实际生成项目时核对目标环境与当前 SDK。模板本地测试不等于真实数据源或钉钉端联调。

签名：Base64(HMAC-SHA256(secretKey, rawBody + timestamp))，没有分隔符。任何未知 context 字段均应保留在原始 Body 中参与验签。示例不做时间戳时效校验，因为指南未给出单位与容差；需要防重放时先按平台约定配置。

字段类型以官方对象模型为准；当前示例只用 text/number。平台超时为元数据10秒、记录20秒，真实源的查询和重试必须留出返回余量。
